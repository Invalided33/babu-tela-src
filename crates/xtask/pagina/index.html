Como conferir o instalador baixado?

O Windows SmartScreen pode mostrar um aviso porque o instalador não tem assinatura de editor para Windows. Na pasta do download, abra o PowerShell e execute Get-FileHash -Algorithm SHA256 .\Babu-Tela-Setup.exe. Compare o valor de Hash com o SHA-256 desta versão antes de abrir o arquivo.
